PROFESSION DETECTION

Before reorganizing the draft:

1. Infer the user's primary professional domain from:

   * Original skills input
   * User answers
   * Current draft
   * Refinement request

2. Create categories that are commonly used in resumes for that profession.

3. Use industry-standard category names whenever possible.

4. Do not force profession-specific skills into unrelated categories.

5. If the user has skills spanning multiple domains, organize them around their primary professional focus.

ATS KEYWORD PRESERVATION

1. Preserve specific recruiter-searchable keywords whenever supported by the user's information.

2. Do not replace specific skills with broader categories if the specific skill provides greater ATS value.

3. Prefer specific terms over generic summaries.

Examples:

Technology:

* Preserve "Azure Functions" instead of "Cloud"
* Preserve "OpenAI APIs" instead of "AI"
* Preserve "PostgreSQL" instead of "Databases"

Healthcare:

* Preserve "Epic EMR" instead of "Healthcare Systems"
* Preserve "ICU Patient Care" instead of "Patient Care"

Finance:

* Preserve "QuickBooks" instead of "Accounting Software"
* Preserve "Tax Preparation" instead of "Accounting"

Education:

* Preserve "Google Classroom" instead of "Educational Technology"
* Preserve "Curriculum Development" instead of "Teaching"

General Rule:
Specific > Broad

CATEGORIZATION RULES

1. Categorize every skill into exactly one category.

2. Use concise, recruiter-friendly category names.

3. Group related skills together.

4. Create new categories when necessary rather than forcing unrelated skills together.

5. Avoid excessive fragmentation.

6. Categories should be easy for recruiters and ATS systems to scan.

FINAL QUALITY CHECK

Before generating the final Skills section:

1. Remove duplicates.
2. Verify every skill is supported by user information.
3. Ensure each skill appears only once.
4. Preserve important ATS keywords.
5. Remove unsupported or low-value entries.
6. Verify categories match the user's profession.
7. Use consistent naming and capitalization.

OUTPUT REQUIREMENTS

Return only the revised Skills section.

Do not:

* Explain changes
* Provide rationale
* Ask follow-up questions
* Include notes or commentary
* Include confidence scores

Return only the final ATS-ready Skills section.
